# Remaining student services: Tasks, Admissions, Tools, and Quick Links

Prepared November 15, 2026. This revision is approved for publication through the GitHub Pages workflow.

The supplied original Catalyst screenshots define the visible names, grouping, and order. This expansion restores those destinations in the existing dark red workspace. Seventy-three unique internal destinations cover seven Tasks views/details, twenty admission entries, fourteen tools, and thirty-two quick links/office/contact entries. Four workspace root pages organize them. Existing academic, profile, finance, scholarship, and reminder behavior remains available.

## Implementation

- `workspace-directory.js`: ordered metadata, official URLs, resource search, scenario operations, safe hydration, and sample letter export.
- `Tasks.svelte`: service indicators, sample to-do records, status/search/sort controls, and local review notes.
- `WorkspaceDirectory.svelte`: admissions/tools/quick-link directories and resource views.
- `WorkspaceSectionNav.svelte`: contextual sidebar/mobile hierarchy.
- `WhatIf.svelte`: shared scenario UI used by AcademicPlanning in either entry point.
- `model.js`: additive workspace state; version-2 students load defaults without resetting existing enrollment, plans, contacts, or preferences. Saved resources, reviews, preparation notes, and scenarios stay isolated by selected student.

- All 52 behavioral tests pass, including eight new tests for hierarchy, combined search/filter behavior, canonical shortcuts, immutable scenario saving, corrupt storage rejection, additive hydration/student isolation, unofficial letter exports, and separation of review notes from registration holds.
