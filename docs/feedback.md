| Perspective | Feedback | Possible design response |
| --- | --- | --- |
| First-year student | “The prerequisite code doesn’t mean much to me yet. Seeing the course name beside it would help.” | Show prerequisite names alongside course codes. |
| Graduating senior | “The confirmation number is reassuring. I’d keep that screen because adding something to a cart doesn’t feel like finishing registration.” | Preserve the explicit receipt and enrollment status. |
| Commuter student | “I care about how many days I have to come to campus. A way to find sections that fit into fewer days would be useful.” | Explore a schedule-planning filter for campus days. |
| Student working part time | “Filtering by day helps, but I also need classes after work. Could I search for classes starting after a certain time?” | Consider start/end-time filters. |
| Student using a phone | “There’s a lot of useful information on each course. I’d want the section time and Add to cart button to be the easiest things to spot.” | Review mobile section hierarchy and spacing. |
| Transfer student | “Where would my transferred classes show up? I’d want to know whether they satisfy a requirement or just count toward credits.” | Explain transfer-credit handling as a future capability. |
| Student considering a full section | “The waitlist message makes sense, but I’d still wonder about my position and whether I’ll get notified.” | Make unavailable waitlist capabilities explicit. |
| Keyboard user | “The keyboard search is useful. It would help if the shortcut hint showed the right keys for my computer.” | Display platform-appropriate shortcut hints. |
| Student planning graduation | “Separating earned and in-progress credits helps. I’d make the assumption about passing current classes more noticeable near the remaining-credit number.” | Strengthen the conditional-credit explanation. |
| Student managing several deadlines | “‘Before next semester’ feels vague. For a real portal, I’d want an exact deadline and a clear indication of what’s urgent.” | Explore dated tasks and urgency labels when verified dates exist. |
| Student who prefers the existing layout | “The new layout looks cleaner, but I’d need a little time to learn where familiar options moved. A short guide could help.” | Consider a brief optional orientation to the new navigation. |

These responses suggest possible revisions; they do not establish usability improvements or document completed changes.
